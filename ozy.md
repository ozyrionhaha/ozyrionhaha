## What I Build

A lot of my work revolves around Discord.

I've built bots and systems for moderation, security, verification, tickets, giveaways, economy, AI, Roblox integrations, backups, restoration, automation, and general server management.

I care about making things actually work rather than just looking like they work. If a command says it created something, it should actually create it. If something fails, I'd rather show the real error and deal with it than hide the problem.

## Atomic

**Atomic** is one of my Discord bot projects.

It's focused on server management, moderation, automation, security, and utilities. It's also a place where I experiment with new Discord features and ideas.

## Ozyy

**Ozyy** is another major Discord project I've worked on.

What started as an experiment grew into a much larger bot with moderation, AI, tickets, security, verification, economy, giveaways, and other server features.

It's one of the projects that taught me a lot about taking a simple idea and gradually turning it into something much bigger.

## Verity

**Verity** is an AI-focused Discord bot I've worked on.

I've used it to experiment with AI conversations, integrations, automated responses, premium features, and bringing AI into an actual application instead of keeping it limited to a chat window.

I'm especially interested in what happens when AI becomes an actual part of a product rather than being the entire product.

## oCyz

**oCyz** is a programming language I've worked on myself.

It's a low-level project involving x86-64 Assembly. Building my own language has been one of the more interesting things I've worked on because it pushed me way outside the usual application-development mindset.

It got me interested in things like parsing, memory, CPU architecture, compilers, and what actually happens between writing code and a computer executing it.

## AI

I've spent a lot of time experimenting with AI and local models.

I've worked with Ollama, local LLMs, model APIs, AI-powered applications, and AI integrations for my own projects.

I'm not only interested in using AI. I also like experimenting with what can be built around it and how it can fit into real applications.

## Game Development

I've also spent time working on games, mainly with Roblox Studio and Godot.

I've experimented with gameplay systems, UI, mechanics, scripting, and the general process of turning an idea into something playable.

Game development is especially fun because you get to see the result of your code immediately.

## Low-Level Programming

Sometimes I like going deeper than normal application development.

I've worked with x86-64 Assembly and enjoy learning about things like registers, instructions, memory, CPU architecture, and what actually happens underneath higher-level code.

It's a completely different way of thinking compared to writing a normal application, which is exactly why I find it interesting.

## Why I Code

Honestly, mostly because I enjoy it.

I like having an idea in my head and turning it into something real. Sometimes that means spending hours hunting down one stupid bug. Sometimes it means rewriting something because my first approach was terrible. And sometimes it means learning an entirely new technology just to build one feature.

I'm still learning, and I definitely don't know everything. I don't think I'll ever stop learning.

I just want to keep building bigger, stranger, and more interesting things.
